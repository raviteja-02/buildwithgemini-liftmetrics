# My agent: LiftMetrics (Workout & PR Coach)
One-liner: A conversational agent that helps fitness enthusiasts build personalized workout routines, log training sessions, and track PRs with a catalog of exercises and visual form guides.

Tool coverage:
- Memory: User fitness goals, current routine, past session logs, and personal records (PRs) across exercises
- Tools: Log workout sessions, record/retrieve PRs, search exercise catalog, and get workout recommendations
- Catalog/UI: Exercise database (muscle groups, equipment, sets/reps) and workout plan tables rendered via A2UI
- Image gen: Infographic and posture diagrams showing proper exercise form, key cues, and setup
- Sandbox: 1-rep max (1RM) estimations, weekly volume load math, and progress metric calculations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for 1RM/volume calculations and progress charting
